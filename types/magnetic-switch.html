Magnetic switch

No contacts at all. A magnet moves inside the switch and a sensor reads where it is, so the keyboard knows the position of every key continuously.

How it works

There is a small magnet on the stem and a Hall-effect sensor on the board below it. Press the key and the magnet moves closer. The sensor reads the magnetic field and turns it into a position, continuously, rather than a single on or off.

Because the position is a number, the actuation point is set in firmware rather than fixed in the switch. A key can be told to register at 0.1 mm or at 4 mm, per key, from software.

Nothing touches, so there is no contact wear and no debounce delay. It also allows rapid trigger: the key resets the moment it starts moving back up instead of waiting to pass a fixed point, so a fast double press reads as two presses.

Some boards read the keys up to 8000 times per second, which is one reading every 0.125 ms. All of it happens inside the keyboard, so it works with any computer.

The numbers

Typical figures for this type. Exact values vary by switch and by board.

Sensing
Hall effect or TMR; the magnet never touches a contact
Total travel
Usually 3.4 to 4.0 mm
Actuation point
Adjustable, typically 0.1 to 4.0 mm
Rapid trigger
Per key; sensitivity down to 0.01 mm on some boards
Polling
1000 Hz standard, up to 8000 Hz (0.125 ms)
Rated life
No contact wear, so the spring and stem set the limit
Sound
Mechanical feel; the switch and case set the sound

Who it suits

Good for

  • Setting your own actuation point
  • Fast repeated presses
  • Avoiding contact wear
  • A keyboard that can be reconfigured

Less good for

  • A fixed, purely mechanical feel
  • Boards that need no software at all
